実写（カメラで撮った映像）向けの既定値に切り替える: model=homography（射影変換）、projection=auto（長いパンは円筒投影）、lens k1=auto（レンズ歪みを推定して補正）、 frame quality=on（ボケ / ブレたフレームを、良いフレームで足りる画素では使わない）、sharp sigma=1、blend detect=on（フレームレート変換で混ざったフレームを除外）、 deinterlace=auto、exposure=on + vignette（周辺減光）、motion reject=on。「実写向け」欄で個別に上書きできる（アニメでも使える）
テロップ（画面に固定された文字・ロゴ）を消したい場合に有効にする。有効時はズーム中心付近の動かない細線をテロップと誤判定して消すことがあるので、細線が消えるなら span を大きく

homography モデルの投影面。auto はパン角が cyl min span 度を超えたら円筒。focal 0 = ペアホモグラフィから推定
放射歪み係数（負 = 樽型）。auto / off / 数値。空欄 = default（実写なら auto）。補正したフレームで位置合わせと合成を行う
近傍 ±window フレームより鮮明度が thr 倍未満のフレーム（ボケ / ブレ）を、良いフレームだけで min samples 以上ある画素では使わない。sharp sigma = 鮮明度を測る前のぼかし（ノイズ対策、実写 1）
blend detect: 前後フレームの混合で説明できるフレーム（フレームレート変換）を除外。deinterlace: 櫛状パターンを検出して片フィールド補間。vignette: 露出補正に放射状の減光（乗算）を加える。motion reject: 画素ごとに中央値から外れた標本の第 2 クラスタが時間的に広く散らばっていれば背景として選ぶ（ゆっくり通過する動体。止まった物は anchor frame で）
静止オーバーレイ検出
有効/無効の切替はパラメータ欄の上の「静止オーバーレイ検出」チェックにあります
halo: 静止エッジ周辺の静止画素も除外する半径 px（グロー対策）。close: 前後 N フレームでマスクされていれば埋める（光沢アニメ対策）
合成
最も細部を持つ標本の拡大率 × この値以内の標本だけで合成（ズーム動画の細線保護。0 で無効）
抽出後のフレーム番号。そのフレーム±window が覆う範囲はそれらだけで合成（動くキャラクターをその姿で確定）
フレーム間の明るさの違い（露出・フェード・プレイヤーの周辺グラデーション）を重なりから推定して補正。auto = 画像列では on、動画では off。profile = 全フレーム共通の画面固定の加算プロファイル（プレイヤーのグラデーション等。端に密な折れ線。default = on、実写では off で代わりに vignette）。local = フレームごとの局所オフセット場（長辺セル数、湯気・光の当たり方の違い。0 で無効）。feather = 「blend」出力でフレーム端から N px なだらかに重みを落として重ねる（空欄 = 画像列では短辺の 1/4、動画では無し）
